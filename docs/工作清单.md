## 二、开发工作清单（按建议顺序）

### 第 1 步：GA 遗传算法实现（P0）✅ 2026-10-01 完成
- [x] `algorithm/app/algorithms/ga.py`：自然数编码染色体（路径排列）
- [x] 适应度=路径总航程倒数；锦标赛选择 + OX 顺序交叉 + 交换/逆转变异
- [x] 混合策略：GA + 2-opt 局部搜索（模因算法）+ 贪心解注入，解决纯 GA 过早收敛
- [x] 参数可调（种群 40~120、迭代 600 代、交叉率 0.9、变异率 0.25），20s 时间预算保护
- [x] 返回迭代收敛曲线数据（plan.py 兼容 3/4 元组，schemas/Java/前端全链路透传）
- [x] 前端 MapView 解除 ga 选项禁用 + 结果卡片渲染收敛曲线（SVG）
- 实测：n=30 提升 15.3%、n=60 提升 4.2%、n=100 提升 14.0%（vs greedy 基线），耗时 0.9~2.5s；浏览器 UI 闭环验证通过
- 验收：与 greedy 对比，20+ 航点时总航程明显更优 ✅

### 第 2 步：ACO 蚁群算法实现（P0）✅ 2026-10-01 完成
- [x] `algorithm/app/algorithms/aco.py`：精英蚂蚁系统（Elitist Ant System）
- [x] 转移概率 p∝τ^α·η^β（β=3 距离主导）+ 蒸发(1-ρ) + Q/L 沉积 + 精英权重沉积；numpy 向量化
- [x] 混合策略：每代对当代最优做 2-opt 改进；初始注入贪心解；20s 时间预算保护
- [x] 参数可调（蚂蚁数 16~40 自适应、α=1.0、β=3.0、ρ=0.3、迭代 400 代），收敛曲线全链路透传
- [x] 前端解除 aco 选项禁用，浏览器 UI 闭环验证通过（规划/路径/收敛曲线/落库）
- 附带修复：`ga.py` 的 `_two_opt` 长度累积漂移 bug（内层反转后未重取 perm[i]，claimed 长度会假性变小甚至为负，GA/ACO 共用此函数）；GA 主循环全局最优被当代结果无条件覆盖的问题；ACO 信息素初值 τ0 在"起点与航点同坐标"（距离 0）时爆炸的问题
- 实测：n=20 时 ACO/GA 均 12.35km vs greedy 16.12km（提升 23.4%）；taskId=2 全链路（Java→Python→落库 resultId=46）通过；续航超限 feasible=false 正确
- 验收：解质量与 GA 持平、耗时 4.8s（20s 预算内），收敛曲线可用于论文对比 ✅

## 三、风险与备注

1. **环境**：项目路径含中文，后端不要用 `mvn spring-boot:run`（会 ClassNotFoundException），用 `mvn package` + `java -jar` 或 IDEA 直接运行 UavApplication；控制台乱码执行 `chcp 65001`
2. **全局 Python 环境**已因安装依赖降级 numpy/pydantic，其他项目若受影响可改用 venv
3. **不要动** `docs/api-contract.md` 的既有契约；新增字段走增量扩展
4. 实验用 `algorithm/data/gen_data.py` 固定种子，保证论文数据可复现
5. 三个服务启动顺序：MySQL → FastAPI(:8000) → Spring Boot(:8080) → Vite(:5173)
