# 无人机巡检系统 — Windows 部署说明

> 目标电脑：Windows 10/11
> 所有命令均在 **cmd（命令提示符）** 中执行，也可在 PowerShell 中运行。

---

## 一、环境准备（只需装一次）

| 软件 | 版本要求 | 说明 |
|---|---|---|
| JDK | 17+ | Spring Boot 3 必须 Java 17 及以上 |
| Maven | 3.6+ | 后端打包（或用 IDEA 自带 Maven） |
| Node.js | 18+ | 前端依赖与构建 |
| Python | 3.9+ | 算法服务 |
| MySQL | 8.0 | 数据库，root 密码默认 `123456` |

验证环境是否就绪（在 cmd 中执行）：

```dos
java -version
mvn -version
node -v
python --version
mysql --version
```

> ⚠️ 如果 `mysql --version` 提示找不到命令，说明 MySQL 的 `bin` 目录没加入 PATH。可以手动加，或者用 Navicat / 命令行时写绝对路径。

---

## 二、把项目复制到目标电脑

把整个 `drone-inspection-system` 文件夹拷贝到目标电脑，例如放在 `D:\drone-inspection-system`。

> 不需要拷贝 `node_modules`、`target`、`__pycache__` 这些可再生物件（如果有的话，删掉也没关系，脚本会重新生成）。

---

## 三、初始化数据库（只需做一次）

### 方法 A：用脚本（推荐）

双击运行 `deploy\01-初始化数据库.bat`，或在 cmd 中：

```dos
cd /d D:\drone-inspection-system\deploy
01-初始化数据库.bat
```

脚本会自动创建 `uav_inspection` 数据库并导入 `db\schema.sql`。

### 方法 B：手动导入

打开 MySQL 命令行（用 Navicat 也行），执行：

```sql
CREATE DATABASE IF NOT EXISTS uav_inspection DEFAULT CHARSET utf8mb4;
USE uav_inspection;
SOURCE D:/drone-inspection-system/db/schema.sql;
```

> 如果你的 MySQL root 密码不是 `123456`，需要同时修改两个地方：
> - `backend\src\main\resources\application.yml` 第 14 行的 `password`
> - `deploy\01-初始化数据库.bat` 里的 `DB_PASS`

---

## 四、安装依赖并打包（只需做一次）

双击运行 `deploy\02-安装依赖并打包.bat`，或在 cmd 中：

```dos
cd /d D:\drone-inspection-system\deploy
02-安装依赖并打包.bat
```

脚本会依次完成：
1. 后端：`mvn clean package -DskipTests` → 生成 `backend\target\uav-backend-0.0.1-SNAPSHOT.jar`
2. 前端：`npm install`（下载依赖，只需一次）
3. 算法：`pip install -r requirements.txt`

> 首次运行可能需要 5–15 分钟（取决于网络）。后端打包需要 Maven 能从中央仓库下载依赖。

---

## 五、启动服务

双击运行 `deploy\03-启动服务.bat`，或在 cmd 中：

```dos
cd /d D:\drone-inspection-system\deploy
03-启动服务.bat
```

会弹出三个独立窗口：
| 窗口标题 | 服务 | 地址 |
|---|---|---|
| 算法服务 FastAPI | 路径规划算法 | http://127.0.0.1:8000 |
| 后端 Spring Boot | 业务后端 | http://127.0.0.1:8080 |
| 前端 Vite dev | 前端页面 | http://localhost:5173 |

稍等 10–20 秒（后端启动较慢），然后浏览器打开：

```
http://localhost:5173
```

默认管理员账号：`admin` / `123456`

---

## 六、停止服务

双击运行 `deploy\04-停止服务.bat`，或者直接关掉那三个弹出窗口。

---

## 七、常见问题

### Q1：后端启动报 "Communications link failure"
MySQL 没启动，或 `application.yml` 里的数据库密码不对。检查 MySQL 服务是否在运行（`services.msc` 里找 MySQL80）。

### Q2：前端页面能打开但登录没反应
检查后端窗口是否有报错。确认 `http://127.0.0.1:8080` 能访问（浏览器打开应返回 Whitelabel Error Page，说明后端活着）。

### Q3：算法服务报 "Address already in use"
8000 端口被占了。先跑 `04-停止服务.bat` 再启动，或者在任务管理器里杀掉占用 8000 的进程。

### Q4：规划航线时报错
检查算法服务窗口是否正常。打开 `http://127.0.0.1:8000/health` 应返回 `{"status":"ok"}`。

### Q5：端口冲突怎么办
- 后端 8080：改 `backend\src\main\resources\application.yml` 第 2 行 `server.port`
- 算法 8000：改 `application.yml` 第 30 行 `base-url` + `03-启动服务.bat` 里的端口
- 前端 5173：改 `frontend\vite.config.js` 第 7 行 `port`

改完后需要重新打包后端（`mvn clean package -DskipTests`）。
